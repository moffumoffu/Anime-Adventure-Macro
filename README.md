# BeepBoop - Anime Adventures Macro

AutoHotkey v2 macro for **Anime Adventures** (Roblox).

## Features
- **Gamemodes picker** - Story (all maps, Infinite / Act 1-6, Normal / Hard), Legend, Raid, Dungeon, Infinity Castle, Cursed Womb, Portals, events
- **Contracts** - hardest or easiest ready card first, Play Here or Matchmaking per card
- **Captcha solver** for matchmaking
- **5 presets**, team per gamemode, in-game team switching
- **Workflow editor** for unit placement and upgrades
- **Auto updater** - keeps your settings

## Install
1. Install [AutoHotkey v2](https://www.autohotkey.com/)
2. Download the latest zip from [Releases](../../releases/latest)
3. Unzip it anywhere
4. Run `Macro.ahk`

## Before you start
- Windows display scale **100%**
- Press **F1** to put Roblox in place
- F2 Start / F3 Stop / F4 Pause

## Updating
When a new version is out, the panel shows **Update to vX** at the top. Click it twice, or run `Updater.ahk`.
Your settings in `Lib\Settings` are never touched.
